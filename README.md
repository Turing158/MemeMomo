## 这是什么？

MemeMomo 是一款专注于快速记录和持续查看的 Windows 桌面备忘录。它不是复杂的知识库，也不会把你的内容上传到云端：打开应用，写下一段 Markdown，之后让它安静地停在桌面边缘或变成一张独立便签。

你可以把它当成：**一个随时在手边的 Markdown 草稿本 + 一组可独立摆放的桌面便签**。

## 它能帮你做什么

| | 能力 | 说明 |
| :---: | --- | --- |
| 📝 | **快速记录** | 在顶部编辑器中输入内容，按 `Ctrl + Enter` 立即新增；首行为空的内容不会被提交。 |
| ✨ | **Markdown 编辑** | 所见即所得编辑器支持标题、强调、删除线、列表、任务项、引用、链接、代码、表格、分隔线和图片，底层仍保存为 Markdown 文本。 |
| 💾 | **自动保存** | 编辑停止约 500ms 后自动保存；`Ctrl + Enter` 可立即保存，`Esc` 恢复本次载入时的内容。 |
| 🔀 | **拖拽重排** | 按住卡片即可调整顺序；拖出主窗口后，在释放位置打开独立便签。 |
| 📌 | **独立便签** | 每条备忘录都能弹出成独立窗口，支持编辑、置顶、任务栏按钮、时间戳切换和关闭动画。 |
| ⏰ | **定时提醒** | 为任意备忘录设置精确到秒的提醒，应用驻留托盘时仍会触发；下次启动会补触发已经到期的提醒。 |
| 🧲 | **贴边收起** | 主窗口靠近屏幕四边或角落时可收起为小方块，拖回屏幕内侧即可展开。位置和边缘状态会持久保存。 |
| 🖥️ | **桌面集成** | 支持系统托盘、全局快捷键、窗口置顶、无边框圆角窗口、边缘/角落缩放和单实例唤起。 |
| 🎨 | **界面偏好** | 支持浅色、深色和跟随系统主题，动效可跟随系统、始终开启或关闭；贴边方块大小也可调整。 |
| 🔒 | **本地存储** | 备忘录、设置和图片保存在本机 `%AppData%/MemeMomo/`，不会因为退出应用而丢失。 |

## 快速上手

**1. 安装 .NET 8 SDK**

MemeMomo 当前面向 Windows，开发和运行需要 .NET 8 SDK。发布版本可直接运行生成的 Windows 程序；从源码启动请先安装 SDK。

**2. 启动 MemeMomo**

在仓库根目录执行：

```powershell
dotnet run --project MemeMomo-wpf/MemeMomo.csproj
```

应用默认以紧凑的无边框窗口显示。首次使用时，可以从「设置 → 教程」查看当前快捷键和窗口操作。

**3. 写下第一条备忘录**

在顶部编辑器输入内容，按 `Ctrl + Enter` 新增。点击已有卡片可载入编辑；停止输入后会自动保存。按住卡片拖动可以重排，拖到主窗口外释放则会弹出便签。

## 便签与提醒

便签窗口适合把一条备忘录固定在工作区。标题栏中的图钉可以单独切换置顶，工具栏按钮可以显示或隐藏 Markdown 工具栏，点击时间戳可以在相对时间和完整时间之间切换。

点击时钟按钮即可设置提醒。日期可以直接输入或从日历选择，时间通过时、分、秒滚轮设置，也可以使用「1 分钟后」「10 分钟后」「半小时后」「1 小时后」四个快捷选项。提醒由应用内计时器触发；完全退出 MemeMomo 后不会在后台运行。

## 贴边收起

把主窗口拖到屏幕边缘约 40 像素以内，窗口会收起成一个小圆角方块。方块可以沿边缘移动，拖向屏幕内侧会在光标处恢复窗口；拖到角落时会同时贴合两条边。设置中的「贴边方块大小」支持 30–75 像素实时调整，也可以完全关闭贴边功能。

## 快捷键一览

### 全局快捷键

| 功能 | 默认快捷键 | 说明 |
| --- | --- | --- |
| 切换置顶 | `Ctrl + Alt + T` | 置顶或取消置顶最近激活的主窗口、便签或教程窗口。 |
| 切换便签任务栏图标 | `Ctrl + Alt + B` | 显示或隐藏最近激活便签的任务栏图标。 |
| 最小化到托盘 | `Ctrl + Alt + M` | 隐藏主窗口并保留托盘驻留。 |
| 显示主窗口 | `Ctrl + Alt + N` | 唤起或恢复主窗口。 |
| 快速添加剪贴板 | `Ctrl + Alt + C` | 将剪贴板文本新增为备忘录，可在设置中关闭。 |

所有全局快捷键都可以在「设置 → 快捷键设置」中修改。点击捕获按钮后按下新的组合键，按 `Esc` 留空，右键取消捕获；被其他应用占用或与系统保留组合冲突的快捷键会被拒绝。

### 编辑器按键

| 场景 | 按键 | 作用 |
| --- | --- | --- |
| 新建备忘录 | `Ctrl + Enter` | 创建一条备忘录。 |
| 任意编辑状态 | `Enter` | 插入换行。 |
| Markdown 编辑 | `Ctrl + B` / `Ctrl + I` / `Ctrl + K` | 插入粗体、斜体或链接。 |
| 编辑已有备忘录 | `Ctrl + Enter` | 立即保存并保持当前编辑状态。 |
| 编辑已有备忘录 | `Esc` | 恢复本次载入时的内容。 |

## 设置

设置窗口中的修改会自动保存，并在应用内即时生效：

- 关闭按钮操作：最小化到托盘或直接关闭；
- 剪贴板快速添加，以及添加后是否在鼠标位置显示便签；
- 拖出已有备忘录时复用便签还是创建重复便签；
- 是否启用贴边、主窗口任务栏图标和便签任务栏图标；
- 托盘图标单击或双击显示主窗口；
- 贴边方块大小、主题模式和界面动效；
- 全局快捷键捕获、冲突校验与一键重置；
- 内置教程窗口。

## 运行环境

- Windows 10 / 11；
- .NET 8 SDK（从源码运行或构建时需要）；
- 桌面应用使用 WPF（.NET 8）；
- 不需要网络连接，不包含云同步或远程账户。

MemeMomo 不会替你调用外部 API。除非你主动插入远程图片地址，否则应用只处理你在本机输入或选择的内容。

## 数据存储

应用会在用户目录创建：

```text
%AppData%/MemeMomo/
├── memos.json       # 备忘录与提醒
├── settings.json    # 关闭行为、快捷键、贴边、主题和动效等设置
└── assets/          # 粘贴、拖入或选择的本地图片，按 SHA-256 去重
```

JSON 使用 camelCase 和缩进格式异步保存，并通过信号量保证并发写入安全。加载失败时会静默回退到默认值；删除上述文件后，MemeMomo 会在下次启动时重新创建空数据和默认设置。

## 给开发者

主项目是位于 `MemeMomo-wpf/` 的 WPF 实现，后续开发都在这里进行。`MemeMomo-avalonia/` 是早期的 Avalonia 实现，已停止更新，仅作为历史参考保留。项目不依赖解决方案文件，可直接调用项目文件：

```powershell
# 构建
dotnet build MemeMomo-wpf/MemeMomo.csproj

# 运行
dotnet run --project MemeMomo-wpf/MemeMomo.csproj

# 发布 Windows 程序
dotnet publish MemeMomo-wpf/MemeMomo.csproj -c Release -r win-x64 --self-contained false
```

主要依赖：

- .NET 8 / C#；
- WPF；
- AvalonEdit 6.3.1.120；
- Markdig 0.41.3。

目录职责如下：

```text
MemeMomo-wpf/
├── Views/                 # 主窗口、便签、提醒、设置、教程与托盘菜单
├── Components/            # 控件和自定义对话框
├── Editor/                # Markdown 编辑器宿主
├── ViewModels/            # 主窗口状态与备忘录集合管理
├── Models/                # 备忘录、设置与快捷键模型
├── Services/              # JSON 存储、图片和编辑协调服务
├── Markdown/              # Markdown 解析、格式化和摘要
├── Behaviors/             # 拖拽重排等交互行为
├── Platform/Windows/      # 托盘、全局快捷键与单实例实现
├── Infrastructure/        # 应用启动与基础设施
├── UI/                    # 主题、动效、窗口、贴边与文本辅助逻辑
├── Utils/                 # 时间格式化等通用工具
├── Resources/             # XAML 资源字典
└── Assets/                # 应用图标资源
```
