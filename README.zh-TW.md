## 這是什麼？

Memo 是一款專注於快速記錄與持續查看的 Windows 桌面備忘錄。它不是複雜的知識庫，也不會把你的內容上傳到雲端：開啟應用程式，寫下一段 Markdown，之後讓它安靜地停在桌面邊緣，或變成一張獨立便箋。

你可以把它當成：**一個隨時在手邊的 Markdown 草稿本 + 一組可獨立擺放的桌面便箋**。

## 它能幫你做什麼

| | 能力 | 說明 |
| :---: | --- | --- |
| 📝 | **快速記錄** | 在頂部編輯器輸入內容，按下 `Ctrl + Enter` 立即新增；首行為空的內容不會提交。 |
| ✨ | **Markdown 編輯** | 所見即所得編輯器支援標題、強調、刪除線、清單、任務項目、引用、連結、程式碼、表格、分隔線與圖片，底層仍以 Markdown 文字儲存。 |
| 💾 | **自動儲存** | 停止編輯約 500ms 後自動儲存；`Ctrl + Enter` 可立即儲存，`Esc` 還原本次載入時的內容。 |
| 🔀 | **拖曳重排** | 按住卡片即可調整順序；將卡片拖出主視窗後，在釋放位置開啟獨立便箋。 |
| 📌 | **獨立便箋** | 每則備忘錄都能彈出成獨立視窗，支援編輯、置頂、工作列按鈕、時間戳切換與關閉動畫。 |
| ⏰ | **定時提醒** | 為任意備忘錄設定精確到秒的提醒，應用程式駐留系統匣時仍會觸發；下次啟動會補觸發已到期的提醒。 |
| 🧲 | **貼邊收起** | 主視窗靠近螢幕四邊或角落時可收起為小方塊，拖回螢幕內側即可展開。位置與邊緣狀態會持久儲存。 |
| 🖥️ | **桌面整合** | 支援系統匣、全域快速鍵、視窗置頂、無邊框圓角視窗、邊緣/角落調整大小與單一執行個體喚起。 |
| 🎨 | **介面偏好** | 支援淺色、深色與跟隨系統主題，動效可跟隨系統、始終開啟或關閉；貼邊方塊大小也可調整。 |
| 🔒 | **本機儲存** | 備忘錄、設定與圖片保存在本機 `%AppData%/Memo/`，不會因退出應用程式而遺失。 |

## 快速開始

**1. 安裝 .NET 8 SDK**

Memo 目前面向 Windows，開發與執行需要 .NET 8 SDK。發佈版本可直接執行產生的 Windows 程式；從原始碼啟動前請先安裝 SDK。

**2. 啟動 Memo**

在儲存庫根目錄執行：

```powershell
dotnet run --project Memo-wpf/Memo.csproj
```

應用程式預設以緊湊的無邊框視窗顯示。首次使用時，可從「設定 → 教學」查看目前的快速鍵與視窗操作。

**3. 寫下第一則備忘錄**

在頂部編輯器輸入內容，按下 `Ctrl + Enter` 新增。雙擊已有卡片即可載入編輯；停止輸入後會自動儲存。按住卡片拖曳可以重排，拖到主視窗外釋放則會彈出便箋。

## 便箋與提醒

便箋視窗適合把一則備忘錄固定在工作區。標題列中的圖釘可以單獨切換置頂，工具列按鈕可以顯示或隱藏 Markdown 工具列，點擊時間戳可以在相對時間與完整時間之間切換。

點擊時鐘按鈕即可設定提醒。日期可以直接輸入或從日曆選擇，時間透過時、分、秒滾輪設定，也可以使用「1 分鐘後」「10 分鐘後」「半小時後」「1 小時後」四個快速選項。提醒由應用程式內計時器觸發；完全退出 Memo 後不會在背景執行。

## 貼邊收起

將主視窗拖到螢幕邊緣約 40 像素以內，視窗會收起成小圓角方塊。方塊可以沿邊緣移動，拖向螢幕內側會在游標處還原視窗；拖到角落時會同時貼合兩條邊。設定中的「貼邊方塊大小」支援 30–75 像素即時預覽，也可以完全關閉貼邊功能。

## 快速鍵一覽

### 全域快速鍵

| 功能 | 預設快速鍵 | 說明 |
| --- | --- | --- |
| 切換置頂 | `Ctrl + Alt + T` | 置頂或取消置頂最近啟用的主視窗、便箋或教學視窗。 |
| 切換便箋工作列圖示 | `Ctrl + Alt + B` | 顯示或隱藏最近啟用便箋的工作列圖示。 |
| 最小化到系統匣 | `Ctrl + Alt + M` | 隱藏主視窗並保留系統匣駐留。 |
| 顯示主視窗 | `Ctrl + Alt + N` | 喚起或還原主視窗。 |
| 快速新增剪貼簿 | `Ctrl + Alt + C` | 將剪貼簿文字新增為備忘錄，可在設定中關閉。 |

所有全域快速鍵都可以在「設定 → 快速鍵設定」中修改。點擊擷取按鈕後按下新的組合鍵，按 `Esc` 留空，右鍵取消擷取；被其他應用程式佔用或與系統保留組合衝突的快速鍵會被拒絕。

### 編輯器按鍵

| 場景 | 按鍵 | 作用 |
| --- | --- | --- |
| 新增備忘錄 | `Ctrl + Enter` | 建立一則備忘錄。 |
| 任意編輯狀態 | `Enter` | 插入換行。 |
| Markdown 編輯 | `Ctrl + B` / `Ctrl + I` / `Ctrl + K` | 插入粗體、斜體或連結。 |
| 編輯已有備忘錄 | `Ctrl + Enter` | 立即儲存並保持目前編輯狀態。 |
| 編輯已有備忘錄 | `Esc` | 還原本次載入時的內容。 |

## 設定

設定視窗中的修改會自動儲存，並在應用程式內即時生效：關閉按鈕操作、剪貼簿快速新增、便箋重複策略、貼邊、主視窗與便箋工作列圖示、系統匣點擊習慣、貼邊方塊大小、主題、動效、全域快速鍵與內建教學。重設操作會在確認後還原預設值。

## 執行環境

- Windows 10 / 11；
- .NET 8 SDK（從原始碼執行或建置時需要）；
- 桌面應用程式使用 WPF（.NET 8）；
- 不需要網路連線，不包含雲端同步或遠端帳戶。

Memo 不會替你呼叫外部 API。除非你主動插入遠端圖片網址，否則應用程式只處理你在本機輸入或選取的內容。

## 資料儲存

應用程式會在使用者目錄建立：

```text
%AppData%/Memo/
├── memos.json       # 備忘錄與提醒
├── settings.json    # 關閉行為、快速鍵、貼邊、主題與動效等設定
└── assets/          # 貼上、拖入或選取的本機圖片，按 SHA-256 去重
```

JSON 使用 camelCase 與縮排格式非同步儲存，並透過信號量確保並行寫入安全。載入失敗時會靜默回退至預設值；刪除上述檔案後，Memo 會在下次啟動時重新建立空資料與預設設定。

## 給開發者

主專案是位於 `Memo-wpf/` 的 WPF 實作，後續開發都在這裡進行。`Memo-avalonia/` 是早期的 Avalonia 實作，已停止更新，僅作為歷史參考保留。專案不依賴方案檔，可直接呼叫專案檔：

```powershell
dotnet build Memo-wpf/Memo.csproj
dotnet run --project Memo-wpf/Memo.csproj
dotnet publish Memo-wpf/Memo.csproj -c Release -r win-x64 --self-contained false
```

主要相依套件：.NET 8 / C#、WPF、AvalonEdit 6.3.1.120 與 Markdig 0.41.3。

```text
Memo-wpf/
├── Views/                 # 主視窗、便箋、提醒、設定、教學與系統匣選單
├── Components/            # 控制項與自訂對話框
├── Editor/                # Markdown 編輯器宿主
├── ViewModels/            # 主視窗狀態與備忘錄集合管理
├── Models/                # 備忘錄、設定與快速鍵模型
├── Services/              # JSON 儲存、圖片與編輯協調服務
├── Markdown/              # Markdown 解析、格式化與摘要
├── Behaviors/             # 拖曳重排等互動行為
├── Platform/Windows/      # 系統匣、全域快速鍵與單一執行個體實作
├── Infrastructure/        # 應用程式啟動與基礎設施
├── UI/                    # 主題、動效、視窗、貼邊與文字輔助邏輯
├── Utils/                 # 時間格式化等通用工具
├── Resources/             # XAML 資源字典
└── Assets/                # 應用程式圖示資源
```
